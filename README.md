# Мини-апп «Раскрой»

Интерфейс и расчёты работают в браузере (`index.html`, `styles.css`, `app.js`).
`bot.py` отвечает на `/start` и показывает кнопку открытия приложения.

## Публикация на GitHub Pages

1. Загрузите исходные файлы проекта в репозиторий GitHub. `.gitignore` исключает `.venv`, `.idea`, `.env` и другие локальные файлы. Токен бота задаётся только на компьютере или сервере, где будет работать бот.
2. В репозитории откройте **Settings → Pages → Build and deployment**.
3. Выберите **Source: Deploy from a branch**, ветку с исходными файлами и папку **/(root)**. Нажмите **Save**.
4. Дождитесь публикации и откройте адрес, показанный на странице Pages. Для обычного репозитория он имеет вид `https://LOGIN.github.io/REPOSITORY/`.
5. Проверьте страницу и используйте её полный HTTPS-адрес как `WEBAPP_URL`.

Файл `.nojekyll` позволяет публиковать файлы без обработки Jekyll.
На бесплатном GitHub Pages доступен для публичного репозитория.
GitHub Pages размещает статические файлы; Python-бот запускается отдельно.

## Запуск бота в Windows

Создайте бота командой `/newbot` у [BotFather](https://t.me/BotFather).
В PowerShell, открытом в папке проекта, выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

.\.venv\Scripts\python.exe run_bot.py
```

Перед первым запуском создайте локальный `.env` по образцу `.env.example` и заполните `BOT_TOKEN` и `WEBAPP_URL`.
`run_bot.py` читает этот файл автоматически; переменные окружения, если они уже заданы, имеют приоритет.
Не загружайте заполненный `.env` на GitHub — он исключён через `.gitignore`.
Если `.venv` уже существует, повторно создавать её не нужно.

Для этого проекта адрес приложения: https://stetsenko-s.github.io/raspilbot_bot/.

Откройте личный чат с ботом, отправьте `/start` и нажмите «Открыть раскрой».
Оставьте процесс бота запущенным; остановка — Ctrl+C. Пока компьютер выключен или спит, бот не отвечает на новые команды.
Для постоянной работы разместите бот на сервере. Запускайте только одну копию с данным токеном.

Дополнительно можно настроить кнопку меню через `/setmenubutton` у BotFather, указав тот же адрес приложения.

## Локальная проверка

В папке проекта выполните `python -m http.server 8000 --bind 127.0.0.1` и откройте http://127.0.0.1:8000/.
После изменения файлов обновляйте страницу через Ctrl+F5. Бот для проверки интерфейса и расчётов не нужен.

Детали и все параметры листа сохраняются в браузере. Старые сохранения деталей подхватываются автоматически.
Количество должно быть целым: 1–500 шт. в строке, максимум 5000 деталей в проекте.
Импорт принимает столбцы, разделённые табуляцией или `;`; ошибочные строки остаются в поле для исправления.

Размеры в полях деталей — размеры готового изделия. Включите «Использовать кромку» в нужной карточке и выберите толщину для каждой стороны на прямоугольной схеме: нет, 0,4, 0,8, 1 или 2 мм.
Длина заготовки уменьшается на кромку слева и справа, ширина — на кромку сверху и снизу. Размер заготовки показан под схемой и используется на карте раскроя.
Выключение кромки восстанавливает размер заготовки, сохраняя выбор сторон для следующего включения.
Метраж считается по размерам готовых деталей и количеству размещённых экземпляров, отдельно для каждой толщины. Запас по умолчанию — 0%; ранее сохранённый запас сохраняется.
Детали, которые не помещаются на лист, в метраж не входят. Если после вычета кромки размер заготовки нулевой или отрицательный, приложение сообщает об ошибке.
